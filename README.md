# Muscle Legends Olympic Gym Management System (ML Websys)

A full-featured gym management and Point of Sales (POS) web application built to streamline member tracking, monthly pass renewals, daily check-ins, and financial reporting for gym staff and administrators.

---

## 🚀 Key Features

* **Dashboard Overview:** Real-time metrics tracking active members, inactive members, total members, and active monthly passes.
* **Smart Expiration Alerts:** Automatically filters out expired passes and highlights monthly passes ending in **7 days or less** in red to alert staff.
* **Member & Monthly Pass Management:** Dedicated tabs to view, search, and edit member details or monthly pass expiration dates.
* **Point of Sales (POS) & Check-Ins:** Intelligent search autocomplete for logging customer visits, registering new members, and processing monthly pass extensions.
* **Log History & Financials:** Tracks gross sales, operational expenses, and net sales per shift.

---

## 🛠️ Tech Stack

* **Frontend:** React, JavaScript (ES6+)
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
